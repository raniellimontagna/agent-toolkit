# Frontend Design

Choose a product-appropriate visual direction before coding. Reuse the local
design system, components, spacing, icons, and styling conventions. Give each
viewport one dominant idea, clear primary/secondary actions, and robust loading,
empty, error, focus, hover, disabled, mobile, and narrow-desktop states.

Avoid generic nested cards, decorative blobs, fragile fixed widths, and
viewport-scaled type. Use semantic accessible controls, stable dimensions, and
verify the rendered UI or build before finishing.
