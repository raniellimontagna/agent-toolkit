# Instagram Public Research

Use this research-only skill for market, audience, competitor, campaign, creator,
or content context. Never publish, message, delete, hide, automate engagement,
scrape authenticated-only content, or bypass login, paywalls, rate limits, bot
protections, or platform controls.

## Allowed Sources And Order

1. Prefer first-party exports or Graph API data when the operator has explicit
   authorization.
2. Use public Instagram pages only when accessible without login and permitted
   by the terms; collect public linked brand sources as needed.
3. Record inaccessible/login-gated sources as limitations. Request an export or
   authorized API for private analytics, DMs, demographics, or insights.

## Data To Extract

- Visible profile basics, public links/category/counts, and visible themes.
- Content patterns: topics, offer language, hooks, captions, creative formats,
  cadence inferred from dates, and CTAs.
- Public engagement only when visible; otherwise mark it unavailable.
- Evidence-backed audience/positioning clues, landing-page inputs, and
  SEO/content entities.

## Research Pack Requirements

For every source, record URL, access method, collection time, and whether it was
public, API-authorized, or user-provided. Separate visible facts from inference,
state unavailable fields and why, use concise summaries rather than raw dumps,
and never include private personal data without explicit authorization and need.

Include `Instagram Findings`: sources, visible facts with citations, content and
positioning patterns, landing-page implications, and limitations.
