# Accessibility WCAG

Use semantic native controls first. Keep one logical heading hierarchy, normal
text contrast at 4.5:1 (3:1 for large text/UI), descriptive alt text, labels for
inputs, accessible names for icon-only controls, visible focus, keyboard access,
and no color-only status.

For landing pages, make CTAs real links/buttons, preserve visual and keyboard
order, avoid placeholder-only labels, put useful errors by their field, and
ensure menus, modals, sticky UI, and carousels have an escape path. Respect
reduced motion and keep content usable at narrow widths and zoom.
