# SEO Page

Build SEO into the page: specific title and description, canonical strategy,
Open Graph/Twitter metadata, one clear h1, logical headings, crawlable core copy,
descriptive alt text, and understandable links/CTAs. Prefer fast static output.

Use JSON-LD only when it truthfully represents real page content; preserve
existing robots and sitemap conventions. Avoid thin or keyword-stuffed content,
duplicate metadata, client-heavy rendering, unsized media, and layout shift.
Make claims, entities, pricing/positioning, and proof easy to quote and verify.
