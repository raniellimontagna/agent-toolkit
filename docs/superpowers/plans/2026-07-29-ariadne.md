# Ariadne Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Ariadne as Agent Toolkit's native autonomous coding loop for Claude Code, Codex CLI, OpenCode, Gemini CLI, and Antigravity CLI.

**Architecture:** Route `agent-toolkit ariadne` into an isolated TypeScript subsystem whose core owns PRD state, process lifecycle, quality checks, Git commits, retries, and recovery. Runtime adapters translate the same iteration context into five headless CLI invocations; runtime-neutral state and result files keep the loop deterministic across agents.

**Tech Stack:** Node.js 24, TypeScript 6 with NodeNext modules, Vitest 4, Git subprocesses, `@clack/prompts`, Biome, Bash integration tests, pnpm 11.

## Global Constraints

- Command name: `agent-toolkit ariadne`; do not add another npm package or top-level executable.
- State root: `.ariadne/`; `config.json`, `prd.json`, `progress.md`, and `archive/` are versionable; `lock` and `runs/` are ignored.
- Canonical PRD schema version: `1`; config schema version: `1`.
- Story statuses: `pending`, `in_progress`, `completed`, `blocked`.
- Default attempt limit: exactly `3` attempts per story; there is no default global iteration limit.
- Ariadne owns commits and never pushes, resets, reverts, cleans, checks out over changes, or discards a failed diff.
- A normal run is autonomous by definition; `--dry-run` is the non-mutating inspection path.
- Runtime versions: Claude Code `2.1.220`, Codex CLI `0.145.0`, OpenCode `1.18.8`, Gemini CLI `0.52.0`, Antigravity CLI minimum `1.1.8`.
- Upstream attribution: `snarktank/ralph` commit `6c53cb0b831ebe8739c6a003e22af14902d8b0b5`, MIT license.
- Reviewed upstream SHA-256 values: PRD skill `f5395f014448e1e970cac40b8f814949b7fdbfe0b6db6be275be750895e955ca`, Ralph skill `1de69bb4e0d53a32facbbc8a8732b945e6721ab0955fdefb27136e43fae860be`, license `102b6470e861e782d90a42d9086f48b8a2f38cbc4c0229216bcf0364f79ea5a3`.
- Companion skills are first-party adaptations named `ariadne` and `ariadne-prd`; they install through the existing Custom Skills pipeline.
- Runtime agents may edit project files and applicable `AGENTS.md`; they may not commit or edit Ariadne's canonical PRD/progress files.
- Default tests must not invoke models, require external authentication, or spend credits.
- Every code task ends with its focused Vitest command and a Conventional Commit.
